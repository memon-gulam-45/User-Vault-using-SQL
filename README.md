# User Vault

**User Vault** is a Node.js and SQL-based user management system, created to understand the integration of **Node.js with SQL databases**. It provides functionality to **add, edit, delete, and view users** with a modern and responsive UI. This project serves as a practical learning tool for backend development with Node.js, Express, and SQL.

---

## Features

- Add new users with email, username, and password
- Edit existing user information
- Delete users with password confirmation
- View all users in **responsive table (desktop)** and **cards (mobile)**
- Modern, mobile-friendly UI using Tailwind CSS
- Fully responsive and professional dashboard-style interface

---

## Tech Stack

- **Backend:** Node.js, Express
- **Database:** SQL (MySQL)
- **Templating:** EJS
- **Styling:** Tailwind CSS (via CDN)
- **Utilities:** UUID, Faker.js (optional for test data)
